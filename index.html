📌 About Project

A simple and secure console-based banking system built using Core Java & OOP Concepts. It allows to create accounts, deposit, withdraw, check balance, and manage customers - just like real bank software.

Java OOP File Handling Console App Git & GitHub

⚙️ Features

  • ✔️ Create New Bank Account
  • ✔️ Deposit Money
  • ✔️ Withdraw Money
  • ✔️ Check Balance & Account Details
  • ✔️ List All Accounts
  • ✔️ Secure Input Validation

💻 How to Run Live (Locally)

This is a Java console project. To run:

1. Clone repo:
git clone https://github.com/hassanatsaim-source/-BankManagementSystem.git

2. Compile:
javac -d . src/com/bank/*.java

3. Run:
java com.bank.Main

For online run, you can import this repo into Replit.com and click Run.
